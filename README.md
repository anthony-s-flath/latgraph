# Latgraph

A small Python library for graphing lattices and related concepts with Plotly.

## Requirements

* NumPy
* Plotly
* Kaleido (for SVG export)

## Layout

* `src/graph.py` — lattice-specific graphing functions
* `src/figure.py` — Plotly figure helpers
* `src/style.py` — shared light and dark figure styles
* `src/number_line.py` — one-dimensional number-line helpers
* `main.py` — examples

## Customization

Plot styling is configured in `src/style.py`.
